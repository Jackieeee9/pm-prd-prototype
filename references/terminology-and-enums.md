# 术语与枚举清单

> 用途：Step 0/Step 4 的单一来源。**先定名再改**；改完扫描旧名，残留必须为 0（修订记录中的更名说明除外）。

## 一、术语表（维护在需求文档附录或本文件副本）

| 术语 | 定义 | 禁用别名 | 首次出现位置 |
|---|---|---|---|
| 人工面签视频 | 视频面签系统推送、隶属视频质检任务的数据源 | 人工视频面签、面签视频 | 视频质检章节、数据源表 |

## 二、枚举清单

每个枚举都要在以下位置同时存在，缺一即视为缺陷：

| 对象 | 字段 | 取值 | 筛选 | 列表 | 详情 | 导出 | 正文 |
|---|---|---|---|---|---|---|---|
| 质检任务 | 状态 | 已完成 / 待复检 / 已复检 / 待质检 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 视频质检 | 视频来源 | 场景风控视频 / 人工面签视频 / 兴业视频人工播报 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 人工复检 | 案例标记 | 不标记 / 优秀沟通案例 / 违规典型案例 / 培训素材 | — | — | ✓ | ✓ | ✓ |

## 三、改动后的扫描规则

```bash
# 旧名残留必须为 0
python3 scripts/check_tables_and_terms.py <file.html> --forbid "人工视频面签" --require "人工面签视频"
```

- 允许保留旧名的唯一位置：修订记录里明确写"原 X 更名为 Y"的那一行。
- 注释、示例数据、导出模板文案都算残留。
- 同一概念在不同页面用了不同叫法时，以**业务口径最准确、用户最常说**的那个为准，而不是以先出现的为准。

## 四、高频坑

1. 名称词序不一致（A+B 还是 B+A）——统一后全量替换，不要只改正文。
2. 新增状态只改徽标，漏筛选项/导出字段/流转表/权限表。
3. 枚举扩了但示例数据没扩，评审时看不到新状态。
4. 术语改了但接口文档仍用旧字段名，研发对不上。
