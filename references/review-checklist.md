# 评审自检清单

> Step 7 使用。逐项打勾；任何一项为否，先修再交付。

## 一、结构与可运行性

- [ ] 文件能直接打开，无白屏
- [ ] 内联脚本语法检查通过（`check_inline_js.py`）
- [ ] HTML 标签嵌套无误（`check_html_nesting.py`）
- [ ] 新增弹窗可以打开、关闭，遮罩点击行为与既有弹窗一致
- [ ] 每个新增按钮调用的函数真实存在
- [ ] 表格表头列数与每行单元格数一致

## 二、交互主路径

- [ ] 新增筛选项能选中并影响列表
- [ ] 新增状态在列表、筛选、导出中都可见
- [ ] 表单必填校验有提示，提交后有反馈
- [ ] 弹窗重复打开时状态已重置（勾选、单选框、只读字段）
- [ ] 空数据、越界、非法输入有明确提示文案

## 三、正文与原型一致

- [ ] 功能清单已更新
- [ ] 页面章节的查询条件、列表字段、交互逻辑与实际原型一致
- [ ] 状态流转表与代码中的状态枚举一致
- [ ] 权限矩阵覆盖所有新按钮
- [ ] 数据源/接口章节写清入参、取值、缺失处理、生效范围
- [ ] 导出字段与原型导出实现一致（含文件名规则）

## 四、术语与枚举

- [ ] 旧术语残留为 0
- [ ] 新增枚举在筛选、列表、详情、导出、正文五处齐全
- [ ] 示例数据包含新增状态/类型，评审可见

## 五、修订记录

- [ ] 新版本号在表格顶部
- [ ] 日期、作者齐全
- [ ] 逐条对应需求编号 R#
- [ ] 标明是否涉及原型
- [ ] 与本次实际改动无遗漏、无虚报

## 六、验收与交付

- [ ] 浏览器可交互时已人工点过主路径
- [ ] 浏览器不可用时，已输出可执行的手动验收步骤
- [ ] 交付说明包含 `computer://` 链接与按 R# 的变更摘要
- [ ] 开放问题单独列出，不藏在正文里

## 七、范围控制

- [ ] B 类（仅后端逻辑）需求没有被扩成前端页面
- [ ] 没有顺手重构与本次需求无关的代码
- [ ] 没有为单个场景引入不必要的抽象或配置项
